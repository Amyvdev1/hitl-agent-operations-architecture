# Publication boundary
This repository is a sanitized architecture showcase by Amy V. The examples are newly authored reference modules, not extracted commercial source code. They use synthetic inputs and contain no client records, credentials, private brand identifiers, pricing catalog, production configuration or customer data.

Historical verification of the private build and tests of the public example are separate evidence categories. A passing reference-module test does not reverify the full private platform. System diagrams describe boundaries; they are not proof of deployment or operational outcomes.

Review code, run tests, then read the verification ledger. All examples run offline with Python's standard library. No provider connections are required.
